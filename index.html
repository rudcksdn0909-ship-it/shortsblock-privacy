ShortsBlock 개인정보처리방침

시행일: 2026년 10월 3일 · 개발자: 경찬우 · 문의: rudcksdn0909@gmail.com
요약
ShortsBlock은 어떠한 개인정보도 수집하지 않습니다. 인터넷 통신을 하지 않으며, 광고·분석 도구·외부 서버가 없습니다. 모든 설정은 사용자의 기기 안에만 저장됩니다.

1. 앱 소개

ShortsBlock은 YouTube Shorts, Instagram Reels, TikTok 등 숏폼 영상 피드를 감지하여 이전 화면으로 되돌리는 디지털 디톡스 앱입니다. 숏폼 소비를 줄이고 싶은 사용자가 스스로 설정한 규칙에 따라 동작합니다.

2. 수집하는 개인정보

없습니다. 이름, 이메일, 전화번호, 위치, 연락처, 기기 식별자, 광고 ID 등 어떠한 개인정보도 수집·저장·전송하지 않습니다. 회원가입이나 로그인도 없습니다.

3. 접근성 서비스(AccessibilityService) 사용에 대한 안내

ShortsBlock은 숏폼 화면을 감지하기 위해 Android 접근성 서비스를 사용합니다. 이는 접근성 보조 목적이 아닌, 사용자가 선택한 앱에서 숏폼 피드를 식별하기 위한 핵심 기능 목적의 사용입니다.

항목내용
접근 대상 앱사용자가 앱 내에서 켠 앱에 한함 (YouTube, Instagram, Facebook, TikTok)
읽는 정보해당 앱 화면의 UI 구조(뷰 ID, 컨테이너 텍스트·설명)만을 숏폼 피드 여부 판단에 사용
저장 여부화면 내용은 저장하지 않음. 판단 즉시 메모리에서 폐기
전송 여부외부로 전송하지 않음 (앱에 네트워크 권한 자체가 없음)
다른 앱대상 앱 외의 앱 화면은 접근성 설정상 이벤트를 수신하지 않음

접근성 서비스는 사용자가 Android 설정에서 직접 켜야만 동작하며, 언제든 같은 설정에서 끌 수 있습니다.

4. 기기 내 저장 데이터

다음 설정값만 사용자 기기 내부 저장소(Android DataStore)에 저장되며, 앱을 삭제하면 함께 삭제됩니다.

  • 앱별 차단 켜기/끄기 상태
  • 차단 강도(즉시 차단 / 스와이프 끊기 / 하루 허용량)
  • 설정 잠금 상태 및 잠금 해제 방식, 사용자가 입력한 따라쓰기 문장
  • 오늘 차단 횟수, 오늘 스와이프 횟수 (날짜가 바뀌면 초기화)

이 데이터는 개인을 식별할 수 없으며 기기 밖으로 나가지 않습니다.

5. 사용 권한과 목적

권한목적
접근성 서비스숏폼 피드 감지 및 뒤로 가기 동작 수행
다른 앱 위에 표시 (SYSTEM_ALERT_WINDOW)차단 시 1.5초간 안내 카드 표시
배터리 최적화 제외 요청절전 모드에서 감지 서비스가 중단되지 않도록 함 (선택)

인터넷(INTERNET) 권한은 요청하지 않습니다.

6. 제3자 제공 및 외부 서비스

개인정보를 제3자에게 제공하지 않습니다. 광고 SDK, 분석 도구(Firebase, Google Analytics 등), 크래시 리포팅 도구를 사용하지 않습니다.

7. 아동의 개인정보

이 앱은 어떠한 연령의 사용자로부터도 개인정보를 수집하지 않습니다.

8. 방침의 변경

방침이 변경될 경우 이 페이지에 게시하며, 시행일을 갱신합니다.

ShortsBlock Privacy Policy

Effective: October 3, 2026 · Developer: Chanwoo Kyung · Contact: rudcksdn0909@gmail.com
Summary
ShortsBlock collects no personal data. It has no internet access, no ads, no analytics, and no external servers. All settings stay on your device.

1. About the app

ShortsBlock is a digital-detox app that detects short-form video feeds (YouTube Shorts, Instagram Reels, TikTok, etc.) and navigates back, according to rules the user sets for themselves.

2. Personal data we collect

None. We do not collect, store, or transmit names, email addresses, phone numbers, location, contacts, device identifiers, or advertising IDs. There is no account or sign-in.

3. Use of the Accessibility Service

ShortsBlock uses the Android AccessibilityService API to detect short-form feeds. This is a core-functionality use, not an accessibility-assistance use.

ItemDetail
Target appsOnly apps the user enables in ShortsBlock (YouTube, Instagram, Facebook, TikTok)
Data readUI structure of the target app's screen (view IDs, container text/descriptions), used solely to decide whether a short-form feed is showing
StorageScreen content is never stored; it is discarded immediately after the check
TransmissionNever transmitted — the app does not request the INTERNET permission
Other appsThe service is configured to receive events only from the target packages

The service runs only after the user enables it in Android Settings and can be disabled there at any time.

4. Data stored on the device

The following settings are stored locally (Android DataStore) and are deleted when the app is uninstalled: per-app blocking toggles, blocking mode, settings-lock state and unlock method, a user-entered typing sentence, and today's block/swipe counters (reset daily). None of it identifies a person and none of it leaves the device.

6. Third parties

No data is shared with third parties. No ad SDKs, analytics, or crash-reporting tools are used.

7. Children

The app collects no personal data from users of any age.
